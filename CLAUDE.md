# Working in this repo

Read the [README](README.md) first, then the guide for what you change: [spec](docs/spec-guide.md),
[PLC](docs/plc-guide.md) or [plan](docs/plan-guide.md).

## Commits

- Author: Meelik Kiik <kiik.meelik@gmail.com>.
- No `Co-Authored-By` or other attribution trailers, and no "Generated with" lines, in commit
  messages or pull request descriptions.
- The message names the evidence for a changed spec value ([spec rule 3](docs/spec-guide.md#rules)).

## Never commit

- `data/`: real plant documents with people's names, kept local only (gitignored). Do not quote
  them in the repo; take only practices from them, written generically.
